# Planora 图标

## 文件

- Editable/Planora Light.icon：浅色 Aurora，可在 Icon Composer 中编辑。
- Editable/Planora Dark.icon：深色 Aurora，可在 Icon Composer 中编辑。
- Previews/：两版的 1024 像素成品及 64 像素检查图，使用 26 渲染。

两套工程均包含独立矢量任务条、细边缘与背景，无外部素材依赖。保留四行任务流、12° 上扬及错落圆角端点。

目前明暗版是两个独立设计工程，并未接入 App 的自动外观切换。PNG 用于预览；工程中的源图层保持 1024 方形画布，最终圆角由系统生成。

旧版本和中间文件已归档到废纸篓中的 Planora Icon Drafts 2026-09-07，可恢复。
