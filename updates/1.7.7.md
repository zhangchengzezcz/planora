# Planora 1.7.7

## 中文
- 新增课堂出勤：Mac 侧栏位于课程与消息之间，首页位于学习进度下方；iPhone、iPad 可从首页进入。
- 同步 ManageBac 当前课表周的出勤状态，按已同步的周查看课程明细。区分出席、迟到、缺席和未记录，不将班主任点名统计混入课堂出勤。
- 出勤率为（出席＋迟到）除以已记录课次，未记录不计入分母。更新后请同步一次 ManageBac。
- 已通过 Mac、iOS 构建和课表读取、重复同步测试；真实学校页面的出勤读取结果尚待用户验证，不代表已导入全学期历史。
- 保留 Vendor/Sparkle 和签名更新源；DMG 内置隐藏背景文件夹和 Finder 背景配置。

## English
- Added classroom attendance between Courses and Messages in the Mac sidebar, and below Learning Progress on the Home screen. Available from Home on iPhone and iPad too.
- Reads attendance from the current ManageBac timetable week and displays previously synced weeks. Present, late, absent and unrecorded lessons remain distinct; homeroom totals are not mixed with classroom attendance.
- Attendance rate is (present + late) / recorded lessons. Unrecorded lessons are excluded. Sync ManageBac once after updating.
- Mac and iOS builds and focused timetable/import tests passed. Live school-page extraction still needs user validation; full-term history is not automatically imported.
- Includes vendored Sparkle, a signed update feed, and an embedded hidden DMG background with Finder metadata.

The macOS app is ad-hoc signed, not Developer ID signed or notarized.
macOS 应用使用临时签名，未进行 Developer ID 签名或公证。
