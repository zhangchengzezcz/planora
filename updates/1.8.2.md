# Planora 1.8.2

## 中文

- Mac 横向切换改为原生 NSSegmentedControl，采用大尺寸胶囊、新版尺寸参数，以及 macOS 27 的 valueSelection 角色；点击、按压、拖动与键盘行为由系统控制，不叠加自绘玻璃滑块。
- 成绩、课程分区、周/月日历和任务状态使用统一原生控件。macOS 26 使用兼容系统参数，不调用 27 专属 API。
- 左上角侧栏/新建操作改为原生工具栏分组，移除额外标题栏附件和固定留白。
- 使用统一窗口工具栏与系统全屏常显参数，减少全屏悬停时的布局变化。iPhone/iPad 侧栏和原有分段控件保持不变。

Mac 安装包为临时签名，未经过 Apple 公证。全屏悬停流畅度仍需在用户的实际设备上验证。

## English

- Mac mode switches use native NSSegmentedControl with large capsule controls, modern size metrics and the macOS 27 valueSelection role. The system handles click, press, drag and keyboard interaction without custom glass thumb overlays.
- Grades, course sections, week/month calendar and task status share the native control. macOS 26 uses compatible system settings without calling 27-only APIs.
- Sidebar/new-task actions use a native toolbar group instead of a fixed-width title-bar accessory.
- Unified window toolbars remain visible in full screen using the system API, reducing hover-related layout changes. iPhone/iPad sidebars and segmented pickers are unchanged.

The Mac package is ad-hoc signed, not Apple-notarized. Full-screen hover smoothness still requires verification on the user's actual device.
