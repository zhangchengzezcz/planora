# Planora 1.7.13

## 中文

- 修复删除重复任务末项后无法继续生成后续任务的问题，保留删除未来任务与恢复操作的语义。
- 保存失败时回滚并显示错误，不再继续取消提醒、清除撤销记录或切换课程体系。
- ManageBac 同步区分明确撤回与未知结果，保护手动完成标记，阻止旧连接的后台结果覆盖新连接。
- 时间表仅在完整识别的日期范围内清理已移除课次；历史周与不完整读取不受影响。
- 出勤详情按所选周统计，首页标明历史记录；不再固定使用上海时区。
- 自动备份改用应用数据目录内的原子文件写入，并兼容旧备份迁移。
- Mac 成绩、日历和课程显示切换使用系统玻璃按钮，保留移动端原生分段控件。
- 补充日语帮助内容和搜索回归测试。

## English

- Fixed rolling recurrence after deleting the final occurrence, while preserving future-deletion and restore behavior.
- Failed saves now roll back and report errors before reminder removal, undo clearing, or curriculum changes.
- ManageBac sync distinguishes authoritative changes from unknown results, preserves manual completion, and rejects stale connection results.
- Timetable reconciliation only removes missing lessons inside a completely recognized date range, preserving history and partial scans.
- Attendance details follow the selected week; Home explicitly shows recorded history. Removed the fixed Shanghai time zone.
- Automatic backups now use atomic files in Application Support with legacy migration support.
- Mac grade, calendar, and course display controls use system glass buttons; mobile segmented controls remain native.
- Added Japanese help and search regression coverage.
