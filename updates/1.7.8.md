# Planora 1.7.8

## 中文
- 成绩新增系统分段控件：Mac 和 iPad 首页可切换数字与按时间排列的横向柱状图，课程成绩可切换数字、柱状图与折线图；不同学科以不同颜色区分。iPhone 首页不增加此切换。
- 出勤同步新增独立项目，优先读取 ManageBac 时间表右侧的课堂出勤汇总，逐节课状态作为补充；首页与课程页均可查看出勤。更新后请重新同步一次。
- 修正首页出勤率与单周日期混用的问题。任务详情的分数显示不变。
- Mac 与 iOS 构建及成绩、出勤解析测试通过。真实学校页面的出勤汇总仍需使用者验证。
- 保留 Vendor/Sparkle、签名更新源和带隐藏背景文件夹的 DMG。

## English
- Added a system segmented control for grades. On Mac and iPad, Home switches between numbers and a chronological, horizontally scrolling bar chart; Course grades offer numbers, bars, and lines. Subjects use distinct colors. The iPhone Home screen has no new switch.
- Attendance is now a separate sync item. Planora prefers the classroom attendance overview in ManageBac timetable Details, with per-lesson states as a fallback. Attendance is accessible from Home and Courses. Sync again after updating.
- Removed a misleading single-week date beside the overall Home attendance rate. Task detail grades are unchanged.
- Mac and iOS builds and focused grade/attendance parsing tests passed. Live school-page attendance still needs user validation.
- Includes vendored Sparkle, a signed update feed, and a DMG with an embedded hidden background folder.

The macOS app is ad-hoc signed, not Developer ID signed or notarized.
macOS 应用使用临时签名，未进行 Developer ID 签名或公证。
