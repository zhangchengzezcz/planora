# Planora 1.8.11

## 中文

- 修复从其他应用通过菜单栏打开任务时，窗口恢复后消失、重现及桌面来回切换的问题。先收起菜单栏弹窗，等待应用激活，再恢复已有主窗口；仅在没有已有窗口时打开窗口。
- 任务页右侧采用原生消息、头像、编辑共框。编辑仅在选中可编辑任务时出现，置顶独立居中。
- 移除与双击重复的任务详情按钮，保留双击及右键详情入口。
- 继承 1.8.10 的任务选择崩溃修复，无需重置或重新导入数据。

## English

- Fix menu-bar task activation flicker by dismissing the popover, waiting for application activation and restoring the existing main window instead of reopening it while inactive.
- Group notifications, profile and selected-task Edit in the native right-hand toolbar. Keep Pin centered separately.
- Remove the redundant detail button while retaining double-click and context-menu detail actions.
- Include the 1.8.10 task-selection crash fix. No data reset or reimport is required.

## Verification

- Eleven focused Mac regression tests passed before packaging, including activation sequencing, repeated requests, task-query safety and selected-task toolbar rendering.
- Native toolbar appearance and Edit opening/cancellation were checked in the local build. The user confirmed the menu-bar activation no longer flickered.
- Double-click implementation is unchanged; computer-use tooling did not complete a double-click runtime check.
- Vlog fixes remain local and are not distributed.
- This Mac distribution is ad-hoc signed and is not Apple-notarized.
