# Planora 1.7.3

## 中文
- 修复旧数据库中重复的 ManageBac 课程、Unit、教师、消息和课程表标识导致导入崩溃的问题。保留旧记录，不自动删除用户数据。
- 导入直接读取数据库，避免界面查询尚未刷新时重复插入任务；数据库读取失败时停止导入。
- 数据库明确保存到 Application Support/Planora/Planora.store。首次启动通过 SQLite 一致性备份迁移原 default.store，包括已提交的 WAL 数据，并保留原库。
- 主窗口与设置共用数据容器。打开数据失败时显示中英文错误界面，不清空数据。
- Mac 通知与头像使用统一尺寸的工具栏组，去掉头像重复底框；周历保持七列，内容宽度不足 820 点时才改为纵向，标题与周/月选择左对齐。
- Mac 更新归档和清单已签名；本次不提供 DMG。应用未经 Developer ID 公证。

## English
- Prevent import crashes caused by duplicate ManageBac course, unit, teacher, message and timetable identifiers. Existing records are retained rather than automatically deleted.
- Fetch existing tasks directly from the database to avoid duplicate insertion from stale UI queries. Stop imports when database reads fail.
- Store data explicitly in Application Support/Planora/Planora.store. Migrate the legacy default.store using a consistent SQLite backup, including committed WAL data, while retaining the original store.
- Share one data container between the main window and Settings. Show a localized recovery screen instead of clearing data if opening the store fails.
- Keep notifications and profile in a consistently sized Mac toolbar group without a second avatar background. Keep seven calendar columns until content width falls below 820 points, with a left-aligned calendar heading and week/month selector.
- Signed Mac update archive and feed; no DMG in this release. The app is not Developer ID notarized.
