# Planora 1.8.8

## 中文

- Mac 菜单栏点击任务会打开对应任务检查器，不再只打开主页。
- 主窗口使用系统单窗口场景，重复点击任务、同步或打开应用不再生成主窗口副本。
- 从菜单栏打开任务时，清除搜索与不匹配的任务来源/状态筛选。
- 菜单栏透明模板图标按实际任务条轮廓放大，保留系统深浅色适配。
- 弹出列表保留标题、学科和截止时间；增加高优先级小旗标与逾期时间强调，不改变存储的手动优先级。

## English

- Open the matching task inspector from the Mac menu bar instead of opening Home.
- Reuse the system single main-window scene for repeated task, sync and app-open actions.
- Clear search and incompatible task filters when opening a task.
- Fit the background-free template icon to its visible task-bar artwork while retaining system appearance adaptation.
- Add high-priority flags and overdue-date emphasis without changing stored manual priorities.
