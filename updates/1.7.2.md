# Planora 1.7.2

## 中文
- Mac 新增检查更新、自动检查和可选自动下载；更新包与更新清单启用签名验证。
- 更新框架仅用于 Mac，iPhone 构建不再解析或下载 Sparkle。
- 首页增加周历，支持上一周、下一周、选择日期和周/月切换；日历位于成绩上方。
- 即将到来的任务不再重复当前重点，成绩默认展示三项并支持展开。
- 修复 ManageBac Completed 分组中尚未评分任务的完成状态漏读。
- DMG 提供拖放安装示意背景和中英文安装说明，不修改应用图标。

首次升级：1.7.1 及以前的版本没有更新器，需要手动安装本版一次。
Mac 要求 macOS 26 或更新版本。本版没有 Apple Developer ID 公证。
更新归档的 Ed25519 签名不等同于 Apple 公证。请阅读 DMG 安装说明。

## English
- Mac-only software updates with signed feeds and archives, automatic checks and optional automatic downloads.
- iPhone builds no longer resolve or download Sparkle.
- Home weekly calendar with week navigation, date selection and a month toggle, above grades.
- Remove duplicate focus tasks from upcoming items; expand the three-result preview on demand.
- Recognize ungraded tasks within ManageBac's Completed section.
- Drag-to-install DMG with bilingual instructions and preserved app icons.

Versions 1.7.1 and earlier need one manual installation to gain the updater.
Requires macOS 26 or later. This build is not Apple Developer ID notarized.
