# Planora 1.8.3

## 中文

- 修正 Mac 顶栏重复侧栏按钮和左侧定位。侧栏/新建位于窗口左侧；收起侧栏时保持可用，不进入溢出菜单。通知/头像保持在右侧。
- 通知和头像使用系统工具栏按钮分组，取消固定高度的普通按钮组合，改善头像居中、底部玻璃边缘和交互阴影的布局。
- macOS 27 的分段切换改用原生 NSSegmentedControl 的 tabs 角色，点击、横向拖动和玻璃材质转换由系统处理，不叠加自制动画或延时。macOS 26 保留兼容实现。
- 成绩、课程分区、周/月日历和任务状态共用这一组件，支持键盘和辅助功能选择。iPhone/iPad 原有控件与侧栏不变。

验证：5 项 Mac 回归测试通过；正式版和 Vlog 版 Mac 构建通过。独立测试窗口检查了 macOS 27 的深浅色、点击、横向拖动及选择绑定；用户已确认切换效果与顶栏正常。macOS 26 兼容外观未进行运行验证。

Mac 安装包为临时签名，未经过 Apple 公证。

## English

- Fixed duplicate Mac sidebar buttons and leading toolbar placement. Sidebar/new-task actions sit on the left and remain available when the sidebar is collapsed instead of moving into overflow. Notification/avatar actions remain on the right.
- Notification/avatar actions use system toolbar button grouping instead of a fixed-height plain-button stack, improving avatar centering and the layout of glass edges and interaction shadows.
- On macOS 27, mode selectors use the native NSSegmentedControl tabs role. The system handles clicks, horizontal dragging and glass material transitions without custom animations or delays. macOS 26 retains the compatibility implementation.
- Grades, course sections, week/month calendar and task status share the component, including keyboard and accessibility selection. Existing iPhone/iPad controls and sidebars are unchanged.

Validation: five Mac regression tests passed, and the production and local Vlog Mac builds succeeded. An isolated window checked macOS 27 light/dark appearance, clicks, horizontal dragging and selection binding. The user confirmed the selector appearance and toolbar behavior. macOS 26 compatibility appearance has not been runtime-tested.

The Mac package is ad-hoc signed, not Apple-notarized.
