# Planora 1.7.5

## 中文

Planora 1.7.5 主要修复 iPhone 与 iPad 首页日历的稳定性问题，并进一步完善 Mac 发布与更新流程。

### iPhone / iPad

- 修复首页周视图与月视图切换时可能触发的 UIKit 布局循环崩溃。
- 修复系统 List 单元格高度在两种布局尺寸之间反复变化的问题。
- 调整月历嵌套布局，避免周／月切换时形成循环尺寸反馈。
- 保留现有首页结构、任务数据、SwiftData 数据和 iOS / iPadOS 27 界面逻辑。
- 增加并重新运行首页兼容性回归测试。
- 在 iPhone 与 iPad Simulator 上重新验证相关首页布局。

### Mac

- 保留现有原生 Mac 工作区和 SwiftData 数据架构。
- 保留 Sparkle 2.9.6 更新系统与 Ed25519 更新签名。
- 继续使用独立的 macOS Release 构建。

### DMG

- DMG 安装背景真正存储于磁盘映像内部的隐藏 `.background` 目录。
- Finder 背景配置引用 DMG 卷内资源，不依赖开发 Mac 上的绝对路径。
- DMG 包含 Planora、Applications 快捷方式与 `INSTALLATION.txt`。
- 构建后重新挂载最终 DMG，检查隐藏背景、Finder 配置、应用签名和映像完整性。
- 生成发布 ZIP、DMG 和 SHA-256 校验值。

### 更新

- Mac 更新继续通过 Sparkle signed appcast 发布。
- 更新 ZIP 继续使用 Ed25519 签名验证。
- Sparkle 私钥继续仅存储于发布 Mac 的 Keychain，不写入 Git 仓库。
- 本版本仍不等同于 Apple Developer ID notarization。

## English

Planora 1.7.5 primarily fixes the Home calendar stability issue on iPhone and iPad and further hardens the Mac distribution and update workflow.

### iPhone / iPad

- Fixed a UIKit layout-loop crash that could occur while switching between the weekly and monthly Home calendar.
- Fixed repeated system List row-height oscillation between competing layout sizes.
- Adjusted the nested monthly-calendar layout to avoid cyclic size feedback.
- Preserved the existing Home structure, task data, SwiftData storage, and iOS / iPadOS 27 interface behavior.
- Added and re-ran Home compatibility regression coverage.
- Re-verified the relevant Home layouts on both iPhone and iPad Simulators.

### Mac

- Preserved the native Mac workspace and existing SwiftData architecture.
- Preserved the Sparkle 2.9.6 update system and Ed25519 update signing.
- Continued to use a dedicated macOS Release build.

### DMG

- The installation background is stored inside the disk image under the hidden `.background` directory.
- Finder references the background inside the mounted DMG rather than an absolute path on the development Mac.
- The DMG contains Planora, an Applications shortcut, and `INSTALLATION.txt`.
- The final compressed DMG is mounted again to verify the embedded background, Finder configuration, application signature, and disk-image integrity.
- SHA-256 checksums are generated for the release ZIP and DMG.

### Updates

- Mac updates continue to use a signed Sparkle appcast.
- Update ZIP archives continue to use Ed25519 signature verification.
- The Sparkle private key remains only in the release Mac Keychain and is never committed to Git.
- This release is still separate from Apple Developer ID notarization.
