# Planora 1.8.10

## Critical Fix

- Fixes the 1.8.9 Mac crash when selecting a task. The toolbar query now filters on the persisted `deletedDate` field instead of the computed `isDeleted` property.
- Adds database regression coverage for active, deleted and restored tasks using the exact toolbar predicate.
- No task data migration, deletion or reset is required. Existing 1.8.9 installations can update in place.
- The separately reported menu-bar window flashing is still under investigation. This release does not claim to resolve it.

## 严重问题修复

- 修复 1.8.9 在 Mac 单击任务时崩溃：顶栏查询改用数据库存储字段 `deletedDate`，不再查询计算属性 `isDeleted`。
- 为同一顶栏查询补上正常、删除及恢复任务的数据库回归测试。
- 不需要清除数据、重新导入或迁移。已安装 1.8.9 的用户可以直接更新。
- 菜单栏打开窗口的闪烁问题仍在排查，本版不宣称已解决。

This Mac distribution is ad-hoc signed and is not Apple-notarized.
