# Planora 1.8.6

## 中文

- 紧急恢复 Mac 原有 UI：普通按钮、课程与来源选择、设置、同步和撤销操作恢复 1.8.3 的材质与颜色。
- 原本有玻璃的主按钮恢复原有色彩、渐变与阴影；原本无玻璃的选择项不再强加玻璃。
- 保留已确认的横向模式切换及系统拖动效果、正常顶栏、同步恢复、课表更新、课程跳转和新版启动页。
- iPhone/iPad 不进行此次样式回退。Vlog 项目同步本地修复，不包含在正式发行资产中。

Mac 安装包使用临时签名，未经过 Apple 公证。

## English

- Urgently restore the original Mac UI materials and colors for ordinary buttons, course/source selections, settings, sync and undo actions.
- Restore existing glass buttons' original colors, gradients and shadows; remove newly imposed glass from non-glass selections.
- Preserve approved horizontal controls and native dragging, the toolbar, sync recovery, timetable updates, course navigation and refreshed onboarding.
- iPhone/iPad styling is unchanged. The Vlog project receives the local fix but is not included in release assets.

The Mac package is ad-hoc signed, not Apple-notarized.
