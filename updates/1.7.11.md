# Planora 1.7.11

## 中文

- 新增中英双语帮助中心，支持搜索入门、ManageBac 同步、任务与提醒、课程与日历、成绩与出勤、数据与更新和故障排查。
- Mac 侧栏问号菜单提供帮助中心和常用主题入口；iPhone 与 iPad 可从设置进入。
- 帮助内容说明未评分与未完成的区别、出勤率计算、备份恢复和问题反馈，并保留 1.7.10 的出勤识别修复。
- Mac 安装镜像继续内嵌安装背景；现有 Mac 用户可通过软件更新获取新版。

## English

- Added a searchable Chinese and English Help Center covering setup, ManageBac sync, tasks and reminders, courses and calendars, grades and attendance, data and updates, and troubleshooting.
- Open help and common topics from the Mac sidebar question-mark menu, or from Settings on iPhone and iPad.
- Help explains ungraded versus incomplete work, attendance calculations, backup and restore, and issue reporting. The attendance fixes from 1.7.10 are retained.
- The Mac disk image embeds its installation background. Existing Mac users can install this release through Software Update.
