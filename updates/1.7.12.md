# Planora 1.7.12

## 中文

- 修复其他应用的同名旧数据库阻止首次启动的问题，不迁移或改动无关数据。
- 修复异常提醒日期和重复任务序号可能导致的崩溃，并将通知更新串行化，避免与任务删除交错。
- 断开 ManageBac 时立即取消后台同步；严格校验缓存的学校主机地址。
- 撤销删除兼容重复任务标识，头像采用原子保存，异常成绩不会进入图表计算。
- 成绩柱状图按需加载，出勤列表避免重复分组和筛选，批量取消提醒只读取一次通知队列。
- 合并重复删除逻辑并移除无调用的提醒接口。保留 26 系统兼容分支及 27 的原生滑动操作 API。

功能范围不变。本版本不包含未完成的入场动画或 Vlog 开发者功能。

## English

- An unrelated legacy database no longer prevents a fresh launch; unrelated data is never migrated or modified.
- Invalid reminder dates and overflowing recurrence sequences no longer crash. Notification mutations are serialized to avoid interleaving with task deletion.
- Disconnecting ManageBac immediately cancels background synchronization. Cached school hostnames are validated before navigation.
- Undo tolerates duplicate task identifiers, avatars are saved atomically, and non-finite grades are kept out of chart calculations.
- Grade bars load lazily, attendance avoids repeated grouping and filtering, and batch reminder removal reads notification queues once.
- Consolidated duplicate deletion logic and removed unused reminder entry points. Retained OS 26 compatibility and OS 27 native swipe-action APIs.

The feature set is unchanged. Unfinished entrance animation and Vlog-only developer features are not included.
