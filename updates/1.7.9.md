# Planora 1.7.9

## 中文
- 修复 ManageBac 时间表右侧 Details 默认收起时，出勤汇总无法导入、首页出勤率空白的问题。同步时会展开并读取课堂出勤汇总。
- 将 `TBD` 与 `Not Recorded` 识别为尚未记录；改进浅色课堂背景及边框的出勤状态识别，不把作业提示色当成出勤状态。
- 更新后请重新同步 ManageBac。不会修改学校端的出勤数据。
- 38 项 ManageBac 回归测试通过，iOS 模拟器目标构建通过。真实账户在新版 App 中的完整同步结果仍需核对。
- Mac 保留 Sparkle 签名更新及带内置背景的 DMG；iPhone 和 iPad 不使用 Sparkle。

## English
- Fixed a blank Home attendance rate when ManageBac's timetable Details panel was collapsed. Sync now expands the panel and reads the classroom attendance overview.
- Treats `TBD` and `Not Recorded` as unrecorded, and improves detection of pale lesson backgrounds and borders without interpreting assignment badges as attendance.
- Sync ManageBac again after updating. Planora does not change school attendance data.
- All 38 ManageBac regression tests and the iOS Simulator build passed. End-to-end sync in the updated app still needs checking with a live account.
- The Mac release retains signed Sparkle updates and a DMG with an embedded background. Sparkle is not included on iPhone or iPad.

The macOS app is ad-hoc signed, not Developer ID signed or notarized.
macOS 应用使用临时签名，未进行 Developer ID 签名或公证。
