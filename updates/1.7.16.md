# Planora 1.7.16

## 中文

- 修复前后台同步更新同一连接的统计信息后，导入被错误拒绝的问题。真正的连接更换仍会取消旧同步。
- 导入失败可直接重试，并显示具体错误；失败页提供取消入口，不会把跳过导入伪装为成功。
- 个人资料从偏好设置迁入 Application Support/Planora/LearningProfile.json，兼容旧版迁移，降低清除偏好后重新进入引导的风险。
- 明确数据库、备份、头像、个人资料与缓存的区别，提供仅清理应用缓存的脚本和卸载说明。
- 保留 1.7.15 的 Mac 签名修复。升级替换应用，不重置数据，无需 PKG。
- 第三方清理工具若删除持久数据目录，仍需外部备份恢复；不能保证恢复已经删除的数据。

## English

- Fixed false stale-connection rejection when another sync updates metadata for the same connection. Account changes still invalidate old sessions.
- Failed imports can retry directly and display the underlying error. A cancel action is available without falsely reporting a skipped import as successful.
- Migrated profile persistence from preferences to Application Support/Planora/LearningProfile.json with legacy compatibility.
- Documented persistent data versus disposable cache and added an app-cache-only cleanup script.
- Retains the 1.7.15 Mac signing fix. Updates replace the app without resetting data; no PKG is needed.
- External backups remain necessary if a third-party cleaner deletes persistent user data.
