# Planora 1.7.14

## 中文

- Mac 成绩、周/月及课程显示切换支持横向拖动，按实际按钮位置切换。
- 任务状态切换使用系统 Liquid Glass 按钮，保留状态颜色和拖动操作。
- 保留完整玻璃与动画效果，仅在系统辅助功能要求时降低效果。iPhone、iPad 原生分段控件不变。
- 继承 1.7.13 的数据可靠性、出勤统计、备份及帮助中心修复。

## English

- Added horizontal drag selection to Mac grade, week/month, and course display controls using measured button bounds.
- Task status controls now use system Liquid Glass buttons while retaining status colors and drag selection.
- Full glass and animation effects remain enabled unless reduced by system accessibility preferences. Native iPhone and iPad segmented controls are unchanged.
- Includes the data reliability, attendance, backup, and help fixes from 1.7.13.

## Validation

- Mac Debug builds passed for production and Vlog projects.
- Interactive visual validation across macOS versions remains pending.
