# Planora 1.7.15

## 中文

- 修复临时签名 Mac 安装包在启动时因 Sparkle 库验证失败而退出的问题。
- 临时签名构建使用专用库验证例外，保留其余 Hardened Runtime 保护；打包时拦截缺少该配置的临时签名包。
- 任务数据无需删除。无法启动 1.7.14 的用户请手动下载安装此版本。
- 此包仍为临时签名，未经过 Developer ID 签名或 Apple 公证。

## English

- Fixed a launch-time Sparkle library-validation failure in ad-hoc signed Mac distributions.
- Ad-hoc builds use a dedicated library-validation exception while retaining other Hardened Runtime protections. Packaging rejects ad-hoc runtime builds missing this configuration.
- No task data reset is needed. If 1.7.14 cannot launch, download and install this version manually.
- This distribution remains ad-hoc signed, without Developer ID signing or Apple notarization.
