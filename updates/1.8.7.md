# Planora 1.8.7

## 中文

- 撤掉 Mac 根视图遗留的全局玻璃按钮样式，保留原有页面材质与颜色。
- 通知与头像恢复原生工具栏按钮组，头像固定为 24 点、按钮内容固定为 32 点，避免挤压；使用系统反馈，不叠加手绘阴影。
- 出勤无数据时居中显示；空任务页的筛选栏固定在顶部。
- 状态选项完整显示英文、中文与日文标题；macOS 27 按每个标题的实际宽度排列，避免整条切换栏过宽。
- 保留原生横向拖动和玻璃切换行为。

## English

- Remove the remaining root-level Mac glass button style while preserving existing page materials and colors.
- Restore native notification/profile toolbar grouping with fixed avatar and content dimensions. Use system feedback, without custom shadows.
- Center the attendance empty state and keep filters at the top of an empty task workspace.
- Fit complete localized status labels. On macOS 27, size each text segment individually to avoid excessive spacing.
- Preserve native horizontal tracking and glass transitions.

## Verification

- Focused Mac control/layout regression tests and production Mac/Vlog builds.
- iOS simulator build passed for the shared attendance layout.
- Static toolbar grouping was observed in the running isolated app; the user reported that the appearance was restored. Automated click verification was interrupted by the UI tool connection, so dynamic press feedback is not claimed as fully verified.
- This Mac distribution uses ad-hoc signing and is not Apple-notarized.
