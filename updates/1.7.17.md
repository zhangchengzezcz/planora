# Planora 1.7.17

## 中文

- 新增“撤销最近一次导入”：恢复最近一次 ManageBac 同步或备份导入前的任务、课程、单元、成绩、教师、消息、课表与出勤。
- 新增“清空全部学习数据”，用于移除误导入的课程与任务；个人名称、头像和外观保持不变。
- Mac 任务页新增导入按钮，和课程更新入口共用同步与恢复界面。移动端个人资料也提供恢复操作。
- 撤销或清空后断开 ManageBac，防止后台同步立即重新导入。

注意：撤销恢复点只从本版本开始记录，撤销会替换导入后的学习数据编辑。清空包括个人任务及应用内部恢复备份，请先导出备份。

Mac 包使用临时签名，未经过 Apple 公证。保留现有 Sparkle 更新源与签名密钥；真实设备升级仍需用户验证。

## English

- Undo the latest ManageBac sync or backup import, restoring tasks, courses, units, grades, teachers, messages, timetable and attendance.
- Clear all learning data to remove incorrectly imported records while preserving your name, avatar and appearance.
- Added an import button to the Mac task workspace, sharing the course sync and recovery interface. Mobile profiles also offer recovery actions.
- Both recovery actions disconnect ManageBac to prevent automatic re-import.

Recovery points begin with this version. Undo replaces learning-data edits made after the import. Clearing includes personal tasks and internal recovery backups; export a backup first.

The Mac package is ad-hoc signed, not Apple-notarized. The existing Sparkle feed and signing key are retained; real-device upgrades still require user verification.
